# Add Entry

Add a file to the Scheduler along with the date it should go live, so the Scheduler can swap it in automatically. From an open Scheduler, click **Add Entry**.

<p><img src="../../../../images/websites/scheduler-add-entry.png" alt="Add Entry form" style="width: 45%;"></p>

**Name** | **Description**
:--- | ---
Select a file from the workspace | Click **Browse** to choose the HTML or TPL file this entry should show.
Start Date | Pick the date and time this entry should go live. Once it's the most recent start date that's already passed, this entry becomes the one that's shown.
Submit | Click **Submit** to save the entry.
