# Experiments

A/B Testing is the most essential tool marketers can use to target visitors by testing their responses to varying content. Experiments allow users to test different iterations of content on different pages and track the iterations receiving the most conversions and engagement &mdash; different pieces of copy, images, hero iterations, and sliders.

!!! Note:
Content being tested can't be a page itself; it has to be a file in the web files directory with an .html or .tpl extension.
