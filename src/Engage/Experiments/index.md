# Experiments

Experiments run A/B tests between different versions of content &mdash; copy, images, a hero section, a slider &mdash; and track which version gets more conversions or engagement. Content being tested can't be a page itself; it has to be a file in the web files directory with an .html or .tpl extension.

To create and manage an Experiment, see [Experiments](/tutorials/advanced-development/cms/experiments/) in Tutorials.
