# Update Segment

Edit a Segment's Name or Purpose. From an open Segment, click **Modify**.

<p><img src="../../../../images/engage/update-segment.png" alt="Modify form" style="width: 50%;"></p>

**Name** | **Description**
:--- | ---
Name | The internal name of the Segment.
Purpose | A description of who belongs in this Segment and why.
Submit | Click **Submit** to save your changes.
