# Modify

Edit a Scheduler's Name, Title, or Description.

<p><img src="../../../../images/engage/scheduler-modify.png" alt="Modify form" style="width: 45%;"></p>

**Name** | **Description**
:--- | ---
Name | The internal name of the Scheduler.
Title | The display title shown wherever the Scheduler is listed.
Description | A short description of the Scheduler's purpose.
Submit | Click **Submit** to save your changes.
