# Engage

Engage groups the tools used to reach and test content with specific audiences, separate from the core content-management tools like Websites, Modules, Forms, and Documents. It sits in the left navigation right after those.

Each tool below follows the same pattern: an **Add** page to create a new one, and an **Overview** page &mdash; opened by clicking an existing item in its list &mdash; for adding entries, editing, and permissions.

**Name** | **Description**
:--- | ---
[Add Segment](/engage/add-segment/) | Group contacts by shared criteria so content and campaigns can target a specific audience.
[Add File Group](/engage/add-file-group/) | Manage and display a related set of files together, with their own permissions.
[Add Scheduler](/engage/add-scheduler/) | Automatically swap a page's content in and out on a predefined schedule.
[Add Experiment](/engage/add-experiment/) | Run A/B tests between different versions of content and track which one performs better.
