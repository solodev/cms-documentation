# Engage

Engage groups the tools used to reach and test content with specific audiences, separate from the core content-management tools in Workspace. It sits in the left navigation right after Workspace.

**Name** | **Description**
:--- | ---
[Segments](/engage/segments/) | Group contacts by shared criteria so content and campaigns can target a specific audience.
[File Groups](/engage/file-groups/) | Manage and display a related set of files together, with their own permissions.
[Scheduler](/engage/scheduler/) | Automatically swap a page's content in and out on a predefined schedule.
[Experiments](/engage/experiments/) | Run A/B tests between different versions of content and track which one performs better.
