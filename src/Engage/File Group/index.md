# File Groups

File Groups manage and display a related set of files &mdash; images, documents, and so on &mdash; as a single unit on a web page. They're commonly used for a document list with its own permissions, so authorized users can add or update files in the group without needing access to the page itself. Click a File Group's name to view or manage it.
