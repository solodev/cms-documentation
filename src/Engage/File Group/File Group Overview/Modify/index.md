# Modify

Edit a File Group's name, title, or description.

<p><img src="../../../../images/engage/file-group-modify.png" alt="Modify form" style="width: 45%;"></p>

**Name** | **Description**
:--- | ---
Name | The internal name of the File Group.
Title | The display title shown wherever the group is listed.
Description | A short description of the group's purpose or contents.
Submit | Click **Submit** to save your changes.
