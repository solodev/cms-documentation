# Add Entry

Add a file to the File Group. You can also add an existing file to a group directly from that file, using its **Add to File Group** action.

<p><img src="../../../../images/engage/file-group-add-entry.png" alt="Add Entry form" style="width: 45%;"></p>

**Name** | **Description**
:--- | ---
Select a file from the workspace | Click **Browse** to choose the file this entry should show.
Start Date | Optional. Schedule when this file should be published within the group.
End Date | Optional. Schedule when this file should be removed from the group.
Submit | Click **Submit** to save the entry.
