# Experiment Overview

A/B Testing is the most essential tool marketers can use to target visitors by testing their responses to varying content. An Experiment holds two or more variants &mdash; each a file and a Frequency (traffic-split percentage). On each visit, Solodev picks a variant weighted by Frequency, then tracks Views and Conversions per variant so you can see which one actually performs best.

!!! Note:
Content being tested can't be a page itself; it has to be a file in the web files directory with an .html or .tpl extension.
!!!

Once you've [added an Experiment](/engage/experiment/add-experiment/), it appears in this list. Click its name to open this Overview, which tracks **Views** and **Conversions** per variant plus a **Views Over Time** chart, and manage it.
