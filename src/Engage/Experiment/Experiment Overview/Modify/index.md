Edit an Experiment's name and settings, and manage its variants.

<p><img src="../../../../images/engage/experiment-modify.png" alt="Modify form" class="border"></p>

**Name** | **Description**
:--- | ---
Name | The internal name of the Experiment.
Title | The display title shown wherever the Experiment is listed.
Description | A short description of what's being tested.

## Variants

Each row is one variant &mdash; a file being tested, its traffic share, and its results so far.

<p><img src="../../../../images/engage/experiment-overview.png" alt="Experiment Overview" class="border"></p>

**Name** | **Description**
:--- | ---
Object | The file to include in the Experiment.
Variant | An alternative version of the file being tested against the original.
Active | Check to activate or deactivate this variant.
Frequency | Adjust the slider to set how often this file should appear, relative to the other variants.
Views | The number of times the file has been viewed.
Conversions | The number of times a view resulted in a conversion.
Conversion Rate | The percentage of views that resulted in a conversion.
