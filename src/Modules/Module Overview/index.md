# Module Overview

Manage entries within a module from its overview page. Click **Open** on a row to view or edit that entry. Filter entries with **Filter**/**Date Filter** and **Find**, or select rows with the checkboxes to act on several at once.

<p><img src="../../../images/modules/module-overview.png" alt="Module Overview with entries" style="width: 90%;"></p>

**Name** | **Description** 
:--- | ---
[Add Entry](/modules/module-overview/add-entry/) | Add a new entry to the module.
[Modify](/modules/module-overview/modify/) | Modify the module's name and access additional options, including table schema, permissions, and more.
[Delete](/modules/module-overview/delete/) | Permanently delete a selected entry or entries.
[Import](/modules/module-overview/import/) | Import entries into your module.
[Export](/modules/module-overview/export/) | Export selected entries from your module.
