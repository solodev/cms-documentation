# Export

Download every entry in a module as a CSV file. From the module's overview page, open the **...** menu and click **Export**.

<p><img src="../../../../images/modules/module-export.png" alt="The ... menu with Import and Export"></p>

Export downloads immediately -- there's no confirmation dialog or options to configure, and no way to export only a filtered/selected subset of entries. It always exports the entire module's current entries.

!!! Note:
This is different from **Export Module** in [Modify](/modules/module-overview/modify/)'s Advanced Options, which exports the module's schema/form definition instead of its entry data.
!!!
