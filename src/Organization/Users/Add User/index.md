# Add User

From the [Users](/organization/users/) list, click **Add User**.

<p><img src="../../../images/organization/add-user.png" alt="Add User form"></p>

**Name** | **Description** 
:--- | ---
Email Address(es) | Type an email address and press Enter to add it. You can invite multiple users at once this way.
Group(s) | Which group(s) the new user(s) start in. Defaults to **Default** -- add or remove groups by typing a group's name.
Message | The message included in the invitation email.
Submit | Sends an invitation email to each address, with instructions for logging in.

!!! Tip:
If a user hasn't received their email invitation, ask them to check their spam folder.
!!!
