# Agents

Agents are AI workspaces that can carry out CMS tasks &mdash; through chat threads and automated runs &mdash; against your Solodev deployment. Each Agent workspace is a separate, configured assistant with its own settings, mapping, and connection details.

**Name** | **Description**
:--- | ---
[Add Agent Workspace](/organization/agents/add-agent-workspace/) | Create a new Agent workspace.
[Agent Studio Settings](/organization/agents/agent-studio-settings/) | Configure the agent's identity, model, and behavior.
[Agent Mapping](/organization/agents/agent-mapping/) | Set which website and URL paths the agent is scoped to.
[Agent MCP Settings](/organization/agents/agent-mcp-settings/) | Turn on Solodev CMS tools for the agent over MCP.
[Run an Agent](/organization/agents/run-an-agent/) | Start, view, cancel, or roll back a run.
[Delete Agent Workspace](/organization/agents/delete-agent-workspace/) | Permanently remove an Agent workspace.

!!! Note
Agents act with real CMS permissions through the same authorization rules as a signed-in user &mdash; there's no separate, looser access level for automation. Review a run's changes the same way you'd review any other administrative change, and use rollback if a run needs to be undone.
!!!
