# Agent Studio

Configures the agent's identity, model, and how it presents itself.

**Identity**

Field | Description
--- | ---
Company Name | The name shown as the agent's owner/brand.
Agent Icon | The agent's icon image.
Accent Color | The agent widget's accent color.
Greeting | The opening message the agent shows.
Description | A short description of the agent.

**Behavior**

Field | Description
--- | ---
Model | The AI model the agent runs on.
Prompt Template | The base instructions/prompt the agent uses.
Type | The agent's remote type/integration.
Schedule | An optional schedule for automated runs.
Use project context | Whether the agent uses surrounding project context.
Show map in agent UI | Whether a map is shown in the agent's interface (for location-aware agents).
Google Maps API Key | Required if Show map is enabled.

**Support and Documentation**

Field | Description
--- | ---
Support Email / Support Contact / Support Type | How users are directed to get help from this agent.
Documentation URL / API Documentation URL | Reference links shown alongside the agent.
Phone Number | A contact number associated with the agent, if applicable.

**Access**

Field | Description
--- | ---
Read-only | Restrict the agent to reading CMS data without making changes.
Status | Whether the agent workspace is active.
