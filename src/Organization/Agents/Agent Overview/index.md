# Agent Overview

Configure, run, and manage an existing Agent workspace. Click on an Agent's name from the [Agents](/organization/agents/) list to open it.

**Name** | **Description**
:--- | ---
[Agent Studio](/organization/agents/agent-overview/agent-studio/) | Configure the agent's identity, model, and behavior.
[Edit Mapping](/organization/agents/agent-overview/edit-mapping/) | Set which website and URL paths the agent is scoped to.
[MCP Settings](/organization/agents/agent-overview/mcp-settings/) | Turn on Solodev CMS tools for the agent over MCP.
[Add Agent Run](/organization/agents/agent-overview/add-agent-run/) | Start, view, cancel, or roll back a run.
[Delete](/organization/agents/agent-overview/delete/) | Permanently remove an Agent.
