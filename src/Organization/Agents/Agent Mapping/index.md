# Agent Mapping

Sets which part of your CMS an agent is scoped to.

Field | Description
--- | ---
Website | The website the agent is mapped to.
URL Path Patterns | The path pattern(s) within that website the agent can act on.
Mapping Status | Whether this mapping is active.

!!! Note
Mapping scopes what the agent is intended to work on, not a substitute for permissions &mdash; the agent still only has access to what the underlying CMS user/connection is permitted to do.
!!!
