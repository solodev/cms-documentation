# Agent MCP Settings

Turns on Solodev CMS tools for the agent over MCP (Model Context Protocol), so the agent can call real CMS actions instead of only chatting.

**Name** | **Description**
:--- | ---
Enable Solodev CMS tools for this agent | Turns on the CMS's MCP tool set for this agent.
Generate CMS API Token | Creates the token the agent uses to authenticate its MCP calls.

Once enabled, the CMS MCP tools are available to the agent the same way they'd be to any MCP client &mdash; authenticated as a real CMS user and bound by that user's permissions.
