Source is the combined tree for everything in your CMS deployment &mdash; Websites, Modules, Users, Documents, and Forms all in one place, instead of navigating into each section separately. It's useful when you need to work across the whole system at once: finding an object without knowing which section it lives under, or moving/copying between areas that otherwise live in separate parts of the nav.

<p><img src="../images/source/filesystem.png" alt="Source tree" class="border"></p>

The main catalogs are:

- Websites
- Modules
- Users
- Documents
- Forms

!!!Note:
A catalog only appears in the tree once it contains at least one item &mdash; an empty CMS deployment with no websites yet, for example, won't show a Websites row until you add one.
!!!

## Source Management

Manage any catalog directly from the combined tree. Click into any catalog to manage it with the same options available from its own section. Use **Search** at the top to find a file without browsing the tree.

<img src="../images/source/filesystem2.png" alt="Source management" class="border"></a>

**Name** | **Description**
:--- | ---
[Upload](/documents/document-overview/upload/) | Drag and drop files or browse your computer to upload them to the folder.
[Add Folder](/documents/add-folder/) | Create a new folder and add details such as the name and title.
[Add File](/documents/add-file/) | Create a new file and add details such as the name and title.
[Update Folder](/documents/document-overview/update-folder/) | Change folder details such as the name or title, and perform advanced functions such as deleting the folder.
[Permissions](/documents/document-overview/permissions/) | Manage user access to files and folders by assigning specific roles.
[Copy](/documents/document-overview/copy/) | Create a duplicate of a file.
[Move](/documents/document-overview/move/) | Move a file to a new location.
[Delete](/documents/document-overview/delete/) | Permanently remove a file from the CMS.
