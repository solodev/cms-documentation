Manually add a submission. From the form's overview page, click **Add Entry**.

The fields shown match the form's own schema &mdash; for a Contact Form, the standard Contact fields (First Name, Last Name, Email, Phone, and so on); for a Module Form, the fields defined when you [**add**](/forms/add-form/) the form or later update it in [**Modify**](/forms/form-overview/modify/).

**Name** | **Description**
:--- | ---
*(schema fields)* | One field per column defined in the form's schema.
Submit | Click **Submit** to save the entry.

!!! Note:
On some forms, **Add Entry** may not appear in the toolbar — see the note on [**Form Overview**](/forms/form-overview/). As an alternative, use [**Import**](/forms/form-overview/import/) with a single-row CSV.
!!!
