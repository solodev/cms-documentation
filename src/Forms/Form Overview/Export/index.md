# Export

Download every submission in a form as a CSV file. From the form's overview page, open the **...** menu and click **Export**. This feature is helpful if you use an email marketing platform (Mailchimp, Constant Contact, etc.) and need to batch upload a list of emails.

Export downloads immediately -- there's no confirmation dialog or options to configure, and no way to export only a filtered/selected subset. It always exports the form's entire current set of submissions. Same mechanism as [Module Overview's Export](/modules/module-overview/export/).
