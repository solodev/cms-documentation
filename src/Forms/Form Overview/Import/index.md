# Import

Bulk-load submissions into a form from a CSV file. From the form's overview page, open the **...** menu and click **Import**.

**Name** | **Description**
:--- | ---
Browse | Choose a `.csv` file from your computer. Its columns should match the form's schema field names.
Empty DB | Check this to clear out all existing submissions before importing, instead of adding to them.

Same mechanism as [Module Overview's Import](/modules/module-overview/import/) -- match your file's column headers to the field Names shown in [Modify](/forms/form-overview/modify/)'s Table Schema section.
