# Move File

Relocate a file to a different folder based on your taxonomy. From an open file, click the **...** menu next to **Publish**, then click **Move**.

<p><img src="../../../images/websites/files/move-file.png" alt="Move panel for a file" style="width: 45%;"></p>

**Name** | **Description**
:--- | ---
Move from File | Read-only: the folder the file currently lives in.
To File | Choose a destination folder from the tree. By default the file is saved into its current folder if you don't pick a new one.
Submit | Click **Submit** to move the file.
