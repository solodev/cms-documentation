Relocate a file to a different folder based on your taxonomy. From an open file, click the **...** menu next to **Publish**, then click **Move**.

<p><img src="../../../images/websites/files/move-file.png" alt="Move panel for a file" style="width: 45%;" class="border"></p>

**Name** | **Description**
:--- | ---
Move from Folder | Read-only: the folder the file currently lives in.
To Folder | Choose a destination folder from the tree. By default the file is saved into its current folder if you don't pick a new one.
Submit | Click **Submit** to move the file.

!!!Note:
To rename the file being moved, double-click the file name. Enter the new name and click **Save**. Make sure the checkbox is selected before submitting.
!!!
