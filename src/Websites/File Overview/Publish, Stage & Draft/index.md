# Publish, Stage & Draft

Every file has one workflow-status button in the top right of the code editor. Click the caret next to the workflow-status button to switch which status your changes are saved as.

<p><img src="../../../images/websites/files/publish-stage-draft.png" alt="Publish button with Stage and Draft options" class="border"></p>

**Name** | **Description**
:--- | ---
Publish | Push the file's current code or content to live production. This is the default action.
Stage | Save the file to a staged version for review as part of your workflow, without pushing it live.
Draft | Save a draft version of the file's code or content, visible only to your team.
