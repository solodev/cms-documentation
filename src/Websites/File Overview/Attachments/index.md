# Attachments

Attach supporting files to a file, like a source document or a reference image. From an open file, click the file icon in the icon row above **Publish**.

<p><img src="../../../images/websites/files/attachments-file.png" alt="Attachments panel for a file" style="width: 40%;"></p>

**Name** | **Description**
:--- | ---
Name / Modified | Existing attachments, listed by name and last-modified date.
Select a file | Browse your computer for a file to attach, then it appears in the table above.
