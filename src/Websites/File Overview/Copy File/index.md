Duplicate a file, optionally into a different folder. From an open file, click the **...** menu next to **Publish**, then click **Copy**.

<p><img src="../../../images/websites/files/copy-file.png" alt="Copy panel for a file" style="width: 45%;" class="border"></p>

**Name** | **Description**
:--- | ---
Copy from Folder | Read-only: the folder the file currently lives in.
To Folder | Choose a destination folder from the tree. By default the copy is saved into the same folder as the original.
Submit | Click **Submit** to create the copy.

!!!Note:
To rename the file being copied, double-click the file name. Enter the new name and click **Save**. Make sure the checkbox is selected before submitting.
!!!
