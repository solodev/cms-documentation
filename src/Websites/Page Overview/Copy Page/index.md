Duplicate a page, optionally into a different folder. 

From an open page, click the **...** menu next to **Publish**, then click **Copy**.

<p><img src="../../../images/websites/pages/copy-page.png" alt="Copy panel for a page" style="width: 45%;" class="border"></p>

**Name** | **Description**
:--- | ---
Copy from Folder | Read-only: the folder the page currently lives in.
To Folder | Choose a destination folder from the tree. By default the copy is saved into the same folder as the original.
Submit | Click **Submit** to create the copy.

!!!Note:
To rename the page being copied, double-click the page name. Enter the new name and click **Save**. Make sure the checkbox is selected before submitting.
!!!
