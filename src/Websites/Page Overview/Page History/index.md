Review previous saved versions of a page's code or content, compare any two versions, and restore an older one. From an open page, click the **...** menu next to **Publish**, then click **History**.

<p><img src="../../../images/websites/pages/page-history.png" alt="History panel showing version list and a diff view" class="border" style="width: 75%;"></p>

**Name** | **Description**
:--- | ---
Version | Each saved version of the page, newest first. Click the page name to open that version.
Diff | Click **Compare** to view a side-by-side diff against the version above it.
Created On | The date and time that version was saved.
By | The user who saved that version.
Save as current version | Restore the page to that version.

Selecting **Compare** loads a side-by-side diff at the bottom of the panel, with the changed lines and characters highlighted in both columns so you can see exactly what changed between versions.
