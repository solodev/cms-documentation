# File Group

Insert a [file group](/engage/file-groups/) &mdash; a curated set of files, such as a photo gallery or a document library.

<p><img src="../../../../images/websites/pages/component-rail.png" alt="Component palette rail" style="width: 8%;"></p>

**Step 1**: While editing a page, find the vertical icon rail on the left edge of the page canvas. File Group is the sixth icon from the top.

**Step 2**: Drag it onto an empty region of the canvas. This opens **Select File Group**.

<p><img src="../../../../images/websites/pages/select-filegroup-picker.png" alt="Select File Group picker"></p>

**Name** | **Description**
:--- | ---
Search file group | Filter the list by name.
**Add File Group** | Create a new file group on the spot if the one you need doesn't exist yet.
Results list | [File groups](/engage/file-groups/) that already exist for this website.
Preview pane | Selecting a file group previews its details before you commit.
Choose | Insert the selected file group at the drop location.
