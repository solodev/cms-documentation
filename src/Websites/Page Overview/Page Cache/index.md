Page cache TTL (Time To Live) is the duration a cached page stays in memory before being refreshed or discarded. It's set from the [Metadata panel](/websites/page-overview/meta-column), and only applies once **Cached** is enabled.

You can update the Page Cache time by selecting any of the options from the TTL menu.
