Page cache TTL (Time To Live) is the duration a cached page stays in memory before being refreshed or discarded. It's set from the [Metadata panel](/websites/page-overview/#manage-meta-information-with-the-metadata-panel), and only applies once **Is Cached** is enabled.

**You can update the Page Cache time by:**

1. Selecting any of the options from the menu.

<p><img src="/images/websites/page/page-cache-ttl.jpg" alt="Page cache TTL Menu" style="width: 20%;"></p>

2. Click **Publish**.
