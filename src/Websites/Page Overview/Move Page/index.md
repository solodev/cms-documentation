Relocate a page to a different folder based on your taxonomy. From an open page, click the **...** menu next to **Publish**, then click **Move**.

<p><img src="../../../images/websites/pages/move-page.png" alt="Move panel for a page" style="width: 45%;" class="border"></p>

**Name** | **Description**
:--- | ---
Move from Folder | Read-only: the folder the page currently lives in.
To Folder | Choose a destination folder from the tree. By default the page is saved into its current folder if you don't pick a new one.
Submit | Click **Submit** to move the page.

!!!Note:
To rename the page being moved, double-click the page name. Enter the new name and click **Save**. Make sure the checkbox is selected before submitting.
!!!
