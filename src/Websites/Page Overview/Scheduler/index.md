# Scheduler

Insert a [scheduler](/engage/scheduler/) &mdash; content that automatically rotates or changes on a schedule.

<p><img src="../../../../images/websites/pages/component-rail.png" alt="Component palette rail" style="width: 8%;"></p>

**Step 1**: While editing a page, find the vertical icon rail on the left edge of the page canvas. Scheduler is the seventh icon from the top.

**Step 2**: Drag it onto an empty region of the canvas. This opens **Select Scheduler**.

<p><img src="../../../../images/websites/pages/select-scheduler-picker.png" alt="Select Scheduler picker"></p>

**Name** | **Description**
:--- | ---
Search scheduler | Filter the list by name.
**Add Scheduler** | Create a new scheduler on the spot if the one you need doesn't exist yet.
Results list | [Schedulers](/engage/scheduler/) that already exist for this website.
Preview pane | Selecting a scheduler previews its details before you commit.
Choose | Insert the selected scheduler at the drop location.
