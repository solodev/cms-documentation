# Includes

Quickly check where a file is being used across your website before you edit or delete it. From an open file, click the tree icon in the icon row above **Publish**.

<p><img src="../../../../images/websites/files/includes-file.png" alt="Includes panel for a file" style="width: 40%;"></p>

Solodev lists every page that includes the file, if any. Click a page's name to jump to it. If nothing references the file yet, you'll see **No pages found that include this file**.
