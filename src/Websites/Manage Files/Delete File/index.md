# Delete File

Permanently remove a file from your website. From an open file, click the **...** menu next to **Publish**, then click **Delete**.

<p><img src="../../../../images/websites/files/delete-file.png" alt="Delete confirmation for a file" style="width: 45%;"></p>

**Name** | **Description**
:--- | ---
Name | Confirm which file(s) are checked for deletion.
Submit | Click **Submit** to permanently delete the file. This cannot be undone.

!!!danger Warning:
Deleting a file is permanent. If the file is referenced by a template or included on a page, that reference will break.
!!!
