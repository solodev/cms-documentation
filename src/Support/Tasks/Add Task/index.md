# Add Task

Open the page, file, or module entry the task is about, then click the people icon in the top-right of its editor toolbar to open its task panel. Click **+ Add task**.

<p><img src="../../../images/support/add-task-form.png" alt="New Task form: note, due date, and assignees"></p>

**Name** | **Description**
:--- | ---
Note box | The task's opening note &mdash; what needs to be done. Tasks aren't given a separate title; they're identified in [My Tasks](/support/tasks/) by which file, page, or entry they're attached to.
Calendar icon | Set a due date. Required.
Assignee icon | Start typing a name and select from the list to add one or more assignees. Required.

Click **Submit task**. Every assignee automatically receives an email with the task details.

!!! Tip:
If a member says they didn't get their task email, ask them to check their spam folder.
!!!
