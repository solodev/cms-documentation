# Upload

Add one or more files from your computer into the current folder. From a folder's page, click **Upload**. Optionally you can drag and drop files from your local file system.

<p><img src="../../../images/documents/upload-form.png" alt="Upload Files panel with a drag-and-drop zone" class="border"></p>

**Name** | **Description**
:--- | ---
Drop files here | Drag files from your computer directly onto the panel.
Browse | Click **Browse** to pick files from a file-selection dialog instead.

Each file uploads as soon as it's added and appears in the list below the drop zone with its size and progress. There's no separate Submit step -- once a file finishes uploading, it's already in the folder.
