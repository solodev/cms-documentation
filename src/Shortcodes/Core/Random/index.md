Returns a random whole number between `min` and `max`. By default, `min` is 0 and `max` is 50000.

**Shortcode:**

```js
[random]
```

**Attributes:**

**Attributes** | **Description** 
:--- | ---
```[min]``` | **(Optional)** The lowest number that can be returned. Default: `0`.
```[max]``` | **(Optional)** The highest number that can be returned. Default: `50000`.

**Code Example:**

```js
[random min="1" max="100"]
```

**Output:**

```
42
```
