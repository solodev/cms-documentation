# Admin

The Admin area provides access to several important features of your Solodev CMS. Admin consists of two sections:

<p><img src="../images/admin/admin-menu.png" alt="ADMIN nav section: Settings and API" class="border"></p>

**Name** | **Description** 
:--- | ---
<a href="/admin/settings/">Settings</a> | Collections, Apps, Layouts, Providers, Permissions, Workflow, Reports, and Branding.
<a href="/admin/api/">API</a> | Here, you can manage System and Module APIs and API Keys.
