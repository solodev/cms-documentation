An API key is a unique string of characters that acts like a password, identifying and authorizing your application or account to access to Solodev's APIs to perform actions as an authenticated user.

On the API Keys page, you can view a list of existing keys. Each key has details such as the key name, status, and a secret that can be previewed using the eye icon.

<p><img src="../../../images/admin/api/api-tokens.png" alt="API Tokens" class="border"></p>

**Name** | **Description** 
:--- | ---
[Add API Key](/admin/api/api-keys/add-api-key) | Create a new API key.
Name | The name of the API key.
API Key | The generated key. Click the eye icon to show the full key.
Copy Icon | Copy the API key to your clipboard.
[Make Inactive/Active](/admin/api/api-keys/toggle-api-key) | Turn the API key off or back on.
Version | The API version the key uses.
[Delete](/admin/api/api-keys/delete-api-key) | Permanently delete the API key.
