Click **Preview** on any layout or component to open its real rendered markup in a new tab &mdash; header, footer, and any sample content it ships with, exactly as a page built from it would start out.

The **Preview** panel updates live as you edit. Click **Save Layout** when you're ready, or **Cancel** to discard it.
