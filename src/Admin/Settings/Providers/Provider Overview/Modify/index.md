Edit an existing connection's Name, Description, Default connection flag, Active status, and any provider-specific fields. A secret field (API key, token) can be replaced but is not shown in full once saved.

<p><img src="../../../../../images/admin/settings/providers/update-connection.png" alt="Update Connection" class="border"></p>

!!! Note
Any feature that uses this connection, such as Segments imports, MCP tokens, Git hosting, and SSO login, picks up the updated settings immediately. Deactivating a connection may cause features that depend on it to stop working.
!!!
