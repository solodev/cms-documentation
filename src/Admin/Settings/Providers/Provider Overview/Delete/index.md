Permanently remove a connection, by clicking on the connection you want to delete and expanding the **Advanced** accordion.

<p><img src="../../../../../images/admin/settings/providers/delete-connection.png" alt="Delete Connection" class="border"></p>

**Name** | **Description**
:--- | ---
Type DELETE to confirm | Type **DELETE** (all caps) to enable the button.
Delete | Permanently deletes this workflow rule. This can't be undone.

!!! Note
Removing a provider setting disconnects anything using it. Check what depends on a connection (Segments imports, MCP tokens, Git hosting, SSO login) before deleting it.
!!!
