# Add Provider Setting

1. Go to Admin > Settings > Providers and choose one from **Available Providers**.
2. Fill in the common fields:

Field | Description
--- | ---
Connection Name | A name to identify this connection.
Description | What this connection is used for.
Active | Whether the connection is currently in use.
Default connection | Whether this is the default connection for this provider type, when more than one is configured.

3. Complete whatever provider-specific fields it asks for &mdash; this varies by provider, from an API key to a full OAuth connection (click **Connect** to authorize).
4. Once saved, it appears under **Connected Providers** and becomes available to whatever else in the CMS depends on it.
