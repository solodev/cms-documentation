# Providers

Providers connect the CMS to outside services &mdash; Git hosts, SSO, marketing/contact platforms, AI runtimes, accessibility scanners, and similar integrations. They live under Admin > Settings > Providers, split between **Connected Providers** (already set up) and **Available Providers** (not yet connected).

**Name** | **Description**
:--- | ---
[Add Provider Setting](/admin/settings/providers/add-provider-setting/) | Connect an available provider.
[Update Provider Setting](/admin/settings/providers/update-provider-setting/) | Change an existing connection's settings.
[Delete Provider Setting](/admin/settings/providers/delete-provider-setting/) | Remove a connection.

!!! Note
Individual provider setup (which fields a specific provider needs, and how to obtain its credentials) isn't documented here yet &mdash; each one needs its own page written against a real, working connection rather than guessed from configuration. If you're setting one up, work with your Solodev engineer.
!!!
