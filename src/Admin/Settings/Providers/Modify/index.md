# Modify

Edit an existing connection's Connection Name, Description, Active status, Default connection flag, and any provider-specific fields. A secret field (API key, token) can be replaced but is not shown in full once saved &mdash; use **Copy** if you need the current value elsewhere.

!!! Note
Anything using this connection (Segments imports, MCP tokens, Git hosting, SSO login, and so on) uses the updated settings immediately. Deactivating a connection can break whatever depends on it.
!!!
