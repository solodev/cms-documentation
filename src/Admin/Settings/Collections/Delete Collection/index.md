# Delete Collection

Open the Collection, click the **&hellip;** menu next to **Modify**, then **Delete**.

<p><img src="../../../../images/admin/settings/collections/collection-detail.png" alt="Collection detail page with the ... menu open, showing Delete"></p>

!!! Note
Deleting a Collection removes its generated category pages. The underlying module (the Datatable or Calendar the categories came from) and its entries are not deleted &mdash; only the Collection's page-generation layer on top of them.
!!!
