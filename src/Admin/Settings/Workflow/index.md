Workflows automate tasks across your organization. Each workflow rule watches for a trigger, such as a file changing state, a task being completed, or a form being submitted. When the trigger fires, the rule takes an action, such as sending an email or assigning a task. You can also add a condition so the rule only runs when it matches.

**Name** | **Description**
:--- | ---
[Add Workflow](/admin/settings/workflow/add-workflow/) | Create a new workflow rule.
[Workflow Overview](/admin/settings/workflow/workflow-overview/) | Click a rule's name to manage it &mdash; edit its condition, or delete it.

!!! Note:
Workflow rules scoped to a specific form or module can also be created and managed from that object's own page &mdash; see [Form Overview's Workflow](/forms/form-overview/workflow/) for the Form Submission case. Both entry points manage the exact same underlying rules; this page just isn't filtered to one object.
