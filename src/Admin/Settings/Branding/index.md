Branding controls how the CMS backend itself looks for your organization &mdash; the logo, button colors, custom CSS, and an optional custom dashboard shown after login.

<p><img src="../../../images/admin/settings/branding/branding.png" alt="Branding page, with Custom CSS and Custom Dashboard" class="border"></p>

**Name** | **Description**
:--- | ---
Logo | Click **Browse** to pick a logo from Documents. Recommended size: 360px x 360px.
[Custom CSS](/admin/settings/branding/#custom-css) | Change the primary/secondary button colors and add raw CSS to restyle the backend. Collapsible.
[Custom Dashboard](/admin/settings/branding/#custom-dashboard) | Replace the default Dashboard with your own markup.

## Custom CSS

Customize the look of the CMS backend to match your brand. Set button colors, reset to defaults, or add your own CSS.

<p><img src="../../../images/admin/settings/branding/custom-css.png" alt="Custom CSS panel" class="border"></p>

**Name** | **Description**
:--- | ---
Primary Button Color / Secondary Button Color | Click a swatch to pick a color, or type a hex value directly.
Back to default colors | Reset both colors to the CMS defaults.
Custom CSS | Raw CSS applied on top of the backend's own styles.

## Custom Dashboard

Replace the default Dashboard with your own content. Enable the custom dashboard and add the HTML you want to display.

<p><img src="../../../images/admin/settings/branding/custom-dashboard.png" alt="Custom Dashboard panel" class="border"></p>

**Name** | **Description**
:--- | ---
Enable Custom Dashboard | Turn on to replace the default Dashboard with your own markup below.
Custom Dashboard Markup | The HTML shown in place of the default Dashboard once enabled.
