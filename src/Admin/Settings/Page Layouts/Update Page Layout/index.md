# Update Page Layout

Edit the same fields available on [Add Page Layout](/admin/settings/page-layouts/add-page-layout/) &mdash; Name, Title, Key, Description, Framework, Layout HTML, Preview HTML, Display Rank, and Status.

!!! Note
A layout can be reused across multiple pages. Changing it here changes every page built from it &mdash; use **Preview** before saving, and check a live page afterward.
!!!
