# Add Page Layout

Field | Description
--- | ---
Name | The internal name of the layout.
Title | The display title.
Key | A unique key identifying the layout.
Description | A brief description of what the layout is for.
Base Template | Optionally start from an existing layout instead of a blank one; select **Use as Base** on any layout in the library.
Framework | The CSS/markup framework the layout is built for.
Layout HTML | The layout's markup.
Preview HTML | Sample markup used to render the Preview.
Display Rank | Controls the layout's sort order in the library.
Status | Whether the layout is active and available to use.

Click **Save Layout** when finished, or **Preview** first to check the result.
