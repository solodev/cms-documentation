# Events

Map a [Calendar](/workspace/modules/) entry to a file so the two stay linked. From an open file, click the calendar icon in the icon row above **Publish**.

<p><img src="../../../../images/websites/files/events-file.png" alt="Events panel for a file" style="width: 40%;"></p>

**Name** | **Description**
:--- | ---
Event Title / Module / Start Time | Calendar entries currently mapped to this file.
Select a calendar entry | Browse for a calendar entry to map to this file.
