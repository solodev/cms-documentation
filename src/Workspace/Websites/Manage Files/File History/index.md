# File History

Review previous saved versions of a file's code or content, compare any two versions, and restore an older one. From an open file, click the **...** menu next to **Publish**, then click **History**.

<p><img src="../../../../images/websites/files/history-file.png" alt="History panel showing version list and a diff view" style="width: 80%;"></p>

**Name** | **Description**
:--- | ---
Version | Each saved version of the file, newest first. Click the filename to open that version.
Diff | Click **Compare** to view a side-by-side diff against the version above it.
Created On | The date and time that version was saved.
By | The user who saved that version.
Save as current version | Restore the file to that version.

Selecting **Compare** loads a side-by-side diff at the bottom of the panel, with the changed lines and characters highlighted in both columns so you can see exactly what changed between versions.
