# Generate Sitemap

A sitemap is an .xml file that lists and organizes all the web pages within a site. It helps search engines understand the site's structure and how its pages connect.

From the website dashboard, open the **Update** menu and select **Generate Sitemap**.

**Name** | **Description**
:--- | ---
Select URL | Choose which of the website's addresses (production, staging, etc.) the sitemap should be generated for.
Generate | Starts the sitemap build.

!!! Note
Generating a sitemap runs as a background job and can take several minutes on a large site. Progress is shown while it runs &mdash; don't close the browser tab until it finishes.
!!!
