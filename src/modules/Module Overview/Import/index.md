Bulk-load entries into a module from a CSV file. From the module's overview page, open the **...** menu and click **Import**.

<p><img src="../../../images/modules/module-import.png" alt="Module actions menu with Import highlighted" class="border"></p>

Choose a `.csv` file and click **Submit**.

<p><img src="../../../images/modules/module-import-modal.png" alt="Import flyout: Parse CSV Browse button and Empty DB checkbox" class="border" style="max-width: 45%;"></p>

**Name** | **Description**
:--- | ---
Browse | Choose a `.csv` file from your computer. Its columns should match the module's schema field names.
Empty DB | Check this to clear out all existing entries before importing, instead of adding to them.

!!! Note:
There's no dedicated CSV template download &mdash; match your file's column headers to the field Names shown in [Modify](/modules/module-overview/modify/)'s Table Schema section.
!!!
